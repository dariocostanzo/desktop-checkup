# Security policy

## Reporting a vulnerability

Please do not report a security vulnerability in a public issue. Once GitHub's private vulnerability reporting is enabled for this repository, use **Security → Report a vulnerability** to send a private report to the maintainers.

Until that feature is enabled, contact a repository maintainer privately through GitHub and ask for a secure reporting channel. Include the affected version, what you observed, and steps to reproduce it, but do not include passwords or other secrets.

The maintainers will acknowledge the report, investigate it privately, and coordinate a fix and public notice with the reporter. There is no guaranteed response time yet.
